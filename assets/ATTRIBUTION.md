# 地图标记与烈度图标

## 地图标记 SVG

| 文件 | 用途 |
|------|------|
| `cross.svg` | 预警震中 |
| `red.svg` | 速报震中（绘制尺寸随震级） |
| `green.svg` | 本机位置 |

来源：eewcn（中国地震预警网相关客户端素材）。**已获开发者授权**，可在 EEWView 中使用。  
再分发或商用请自行确认授权范围。

## 烈度 / 震度图标

| 目录 | 标度 | 说明 |
|------|------|------|
| `CSIS/` | 中国烈度（1–11） | 列表与信息头右侧图标 |
| `zd/` | 气象厅震度 | `5R`=5弱、`5Q`=5强；`6R`/`6Q` 同理 |
