# 音效路由

真相源：`assets/sound/catalog.json`  
实现：`crates/jian-audio`  
许可：[`assets/sound/ATTRIBUTION.md`](../assets/sound/ATTRIBUTION.md)

## 路由

| 路由键 | 包 | 用途 |
|--------|-----|------|
| `default_eew` / `jma_eew` | **srev** | 发行 / 更新 / 最终 / 取消 / 震度档 |
| `countdown` | **countdown** | 本地 S 波中文倒计时 |
| `station` | **station** | 测站提示 |
| `ui` | **ui** | 连接与通用通知 |
| `eew` | **eew** | 事件音回退包（原创合成） |

默认事件包 `srev`、倒计时包 `countdown`（设置页不再提供切换）。

## 事件键

| 意图 | 包内键 |
|------|--------|
| 发行 | `issue` |
| 更新 | `update` |
| 最终报 | `final` |
| 取消 | `cancel` |
| 震度档 | `shindo_0` … `shindo_7` |
| 倒计时秒 | `0s` … `10s`、`20s` … `60s` |
| 倒计时循环 | `countdown_loop`（`countdown.wav`） |

## 倒计时

仅在本机 `[local]` 经纬有效、且存在活动预警剩余秒时播报：

| 步骤 | 行为 |
|------|------|
| 剩余 >30 秒 | 仅整十秒语音（60…40），**不**开循环底噪 |
| 剩余 ≤30 秒 | 开启循环底噪（滴滴），**每一整秒边界重启**以对齐 HUD；整十秒与 ≤10 秒播秒档 |
| 到达 0 | 播 `0s`，停止循环 |

无本机位置时不播报倒计时语音。

## 预警事件

**仅 JMA 族**播 SREV；其余机构预警暂不播事件音。对齐要石（Kanameishi）路由：

| 条件 | 音效 |
|------|------|
| 取消报 | `cancel` |
| 首报 | `issue` |
| 报数升高且最终报 | `final` |
| 报数升高 | `update` |
| 警报（`is_warn` / 震度≥5弱）且本事件尚未播过 | 附加 `warn` |
| 非警报且震度≥3且尚未播过 | 附加 `caution` |

`prompt` / `hypocenter` / `detail` / `shindo_*` 为速报/情报用，**暂不接线**。

调查中（`is_assumption` / 震源「調査中」）：仍可播上述事件音，**不**播本地倒计时（对齐要石）。
