# 音效路由

真相源：`media/sound/catalog.json`  
实现：`crates/jian-audio`  
许可：[`media/sound/ATTRIBUTION.md`](../media/sound/ATTRIBUTION.md)

## 路由

| 路由键 | 包 | 用途 |
|--------|-----|------|
| `default_eew` / `jma_eew` | **srev** | 发行 / 更新 / 最终 / 取消 / 震度档 |
| `countdown` | **countdown** | 本地 S 波中文倒计时 |
| `station` | **station** | 测站提示 |
| `ui` | **ui** | 连接与通用通知 |
| `eew` | **eew** | 事件音回退包（原创合成） |

默认事件包 `srev`、倒计时包 `countdown`（设置页不再提供切换）。

## 事件键

| 意图 | 包内键 |
|------|--------|
| 发行 | `issue` |
| 更新 | `update` |
| 最终报 | `final` |
| 取消 | `cancel` |
| 震度档 | `shindo_0` … `shindo_7` |
| 倒计时秒 | `0s` … `10s`、`20s` … `60s` |
| 倒计时循环 | `countdown_loop`（`countdown.wav`） |

## 倒计时

仅在本机 `[local]` 经纬有效、且存在活动预警剩余秒时播报：

| 步骤 | 行为 |
|------|------|
| 剩余 > 开始秒 | 不播（默认开始秒为 10，对齐要石 `countdownStart`） |
| 剩余 ≤ 开始秒 | 循环滴答 `countdown.wav`，每一整秒边界重启以对齐 HUD |
| 语音 | `countdown_speech` 开时：≤10 每秒播地牛语音；11–60 仅整十秒 |
| 仅强有感 | 本机预估日本震度 ≥3 或中国烈度 ≥5 才播 |
| 到达 0 | 播 `0s`，停止循环 |

无本机位置时不播报倒计时语音。

## 预警事件

**仅 JMA 族**播 SREV；其余机构预警暂不播事件音。对齐要石（Kanameishi）路由：

| 条件 | 音效 |
|------|------|
| 取消报 | `cancel` |
| 首报 | `issue` |
| 报数升高且最终报 | `final` |
| 报数升高 | `update` |
| 警报（`is_warn` / 震度≥5弱）且本事件尚未播过 | 附加 `warn` |
| 非警报且震度≥3且尚未播过 | 附加 `caution` |

`prompt` / `hypocenter` / `detail` 为速报/情报用，**暂不接线**。

调查中（`is_assumption` / 震源「調査中」）：仍可播上述事件音，**不**播本地倒计时（对齐要石）。

## 海啸

仅 JMA 海啸情报（顶条有效时）。`grade` → SREV 档位：预报=`tsunami1_*`，注意报=`tsunami2_*`，警报/大海啸=`tsunami3_*`。

| 条件 | 音效 |
|------|------|
| 首报（或解除后再发） | `tsunamiN_issue` |
| 同事件更新（换档/改正） | `tsunamiN_update` |
| 解除报 / 顶条被清空 | `tsunamiN_cancel`（N 取解除前档位） |

启动画面灌入的海啸状态不播。预报到期自动清除也会走解除音。

## 台风

对齐 EEWCN `MapTyphoonLogic`：活跃列表指纹变化且非首包时播 `ui` 包 `notify`（对应 eewcn `hint.wav`）。
