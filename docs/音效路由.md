# 音效路由（P4）

> 更新日期：2026-10-09  
> 实现：`crates/jian-audio`；真相源：`assets/sound/catalog.json`

## 原则

| 路由 | 包 | 说明 |
|------|-----|------|
| `default_eew` / `jma_eew` | **srev** | 发行 / 更新 / 最终 / 取消 / 震度档 |
| `countdown` | **countdown** | 地牛 Wake Up! 中文倒计时 |
| `station` / `ui` | 原创 CC0 | 测站与 UI（文件缺失时仅打日志） |
| `eew` | 原创合成 | SREV 文件缺失时的回退 |

许可与署名见 [`assets/sound/ATTRIBUTION.md`](../assets/sound/ATTRIBUTION.md)。

## Cue → 事件键

| `AudioCue` | 包内键 |
|------------|--------|
| `Issue` | `issue` |
| `Update` | `update` |
| `Final` | `final` |
| `Cancel` | `cancel` |
| `Shindo(n)` | `shindo_{0..7}`（JMA level 0–9 映射到 0–7） |
| `Countdown(s)` | `{s}s`（0–10、20…60） |
| `CountdownLoop(true/false)` | `countdown_loop` ↔ `countdown.wav` |

配置 `[audio] event_pack` / `countdown_pack` 覆盖包名。

## 倒计时状态机

仅当 **本机 `[local]` 经纬有效** 且 UI 有 `countdown_s` 时驱动：

1. 进入倒计时 → 开循环底噪  
2. 剩余秒 ∈ {60,50,…,20} 或 ≤10 → 播对应秒档（每档一次）  
3. 到 0 → 播 `0s`，停循环  

无位置时**禁止**用 demo 数字驱动播报。

## EEW 触发

`AudioEngine::on_eew`：同 `(agency, event_id)` 首次 → `Issue`（+ 可选震度）；`serial` 升高 → `Update` / `Final`；取消 → `Cancel`。  
`is_final` / `is_cancel` 字段待适配器补齐后接入（当前骨架以 Issue/Update 为主）。
