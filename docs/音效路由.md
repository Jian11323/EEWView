# 音效路由

真相源：`media/sound/catalog.json`  
实现：`crates/jian-audio`  
许可：[`media/ATTRIBUTION.md`](../media/ATTRIBUTION.md)（音效一节）

全部音频文件平铺于 `media/sound/` 根目录；`catalog.json` 的 `packs` 仅作逻辑分组，不再对应子目录。

## 路由

| 路由键 | 包 | 用途 |
|--------|-----|------|
| `jma_eew` | **srev** | JMA 预警发行 / 更新 / 最终 / 取消 / 震度档 / 海啸 |
| `default_eew` | **eewcn** | 非 JMA 预警首报 / 更新 / 危急档 / S 波抵达 |
| `record` | **eewcn** | 速报提示 |
| `countdown` | **countdown** | 本地 S 波中文倒计时 |
| `station` | **station** | 测站提示 |
| `ui` | **ui** | 连接与通用通知 |
| `eew` | **eew** | 缺文件时回退（原创合成） |

默认事件包配置 `event_pack = "srev"`（海啸与试听）；非 JMA 预警按路由强制走 `eewcn`。

## 事件键

| 意图 | 包内键 |
|------|--------|
| 发行 | `issue`（SREV / eewcn：未达危急档时 `eewalert`） |
| 危急 | `critical`（eewcn：烈度≥7 或 M≥5 → `eewcritical`） |
| 更新 | `update`（SREV / eewcn 未达危急档时 `eewupdate`） |
| 最终报 | `final`（SREV；eewcn 未达危急档时 `eewupdate`） |
| 取消 | `cancel`（仅 SREV；eewcn 无此文件则回退合成包） |
| 速报 | `record`（eewcn `newrecord`） |
| S 波抵达 | `arrive_s`（eewcn `swavearrive`） |
| 震度档 | `shindo_0` … `shindo_7`（SREV） |
| 倒计时秒 | `0s` … `10s`、`20s` … `60s` |
| 倒计时循环 | `countdown_loop`（`countdown.wav`） |

## 倒计时

仅在本机 `[local]` 经纬有效、且存在活动预警剩余秒时播报：

| 步骤 | 行为 |
|------|------|
| 剩余 > 开始秒 | 不播（默认开始秒为 10，对齐要石 `countdownStart`） |
| 剩余 ≤ 开始秒 | 循环滴答 `countdown.wav`，每一整秒边界重启以对齐 HUD |
| 语音 | `countdown_speech` 开时：≤10 每秒播地牛语音；11–60 仅整十秒 |
| 仅强有感 | 本机预估日本震度 ≥3 或中国烈度 ≥5 才播 |
| 到达 0 | 播 `0s`，停止循环 |

无本机位置时不播报倒计时语音。

## S 波抵达

本机位置有效且倒计时会话算出剩余秒时：剩余首次落到 0（S 波抵达所在地）播 `swavearrive.wav`（与倒计时语音开关无关；启动画面期间不播）。

## 预警事件

| 机构 | 音效包 | 行为 |
|------|--------|------|
| **JMA 族** | SREV | 对齐要石：issue / update / final / cancel，另附 caution / warn |
| **其余机构** | Open EEW CN | 烈度≥7 或 M≥5 → `eewcritical`；否则首报 `eewalert`、报数升高 `eewupdate` |

JMA 附加档：

| 条件 | 音效 |
|------|------|
| 取消报 | `cancel` |
| 首报 | `issue` |
| 报数升高且最终报 | `final` |
| 报数升高 | `update` |
| 警报（`is_warn` / 震度≥5弱）且本事件尚未播过 | 附加 `warn` |
| 非警报且震度≥3且尚未播过 | 附加 `caution` |

调查中（`is_assumption` / 震源「調査中」）：仍可播上述事件音，**不**播本地倒计时（对齐要石）。

## 速报

近时窗口内新条目或实质更新时播 Open EEW CN `newrecord.wav`（与 TTS 开关无关；启动画面灌入不播）。

## 海啸

仅 JMA 海啸情报（顶条有效时）。`grade` → SREV 档位：预报=`tsunami1_*`，注意报=`tsunami2_*`，警报/大海啸=`tsunami3_*`。

| 条件 | 音效 |
|------|------|
| 首报（或解除后再发） | `tsunamiN_issue` |
| 同事件更新（换档/改正） | `tsunamiN_update` |
| 解除报 / 顶条被清空 | `tsunamiN_cancel`（N 取解除前档位） |

启动画面灌入的海啸状态不播。预报到期自动清除也会走解除音。

## 台风

对齐 EEWCN `MapTyphoonLogic`：活跃列表指纹变化且非首包时播 `ui` 包 `notify`（对应 eewcn `hint.wav`）。
