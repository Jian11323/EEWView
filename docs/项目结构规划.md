## 0.1 开源许可证（建议）

**结论（推荐默认）**

| 对象 | 建议许可 | 说明 |
|------|----------|------|
| **自写代码**（`crates/**`、工具脚本） | **Apache-2.0**（已选定，与 GitHub `LICENSE` 一致） | 与 Rust / egui / tokio 生态一致；含专利兜底 |
| **第三方素材** | **各跟原许可**，写在 `ATTRIBUTION.md`，**不要**强行盖成代码同款许可证 | 见下表 |
| **公开 GitHub 发行包** | 代码开源 + 素材分轨；**地牛倒计时不得默认打进「可再分发」开源包**，除非另获书面授权 | 未授权时：仓库用 `.gitignore` / 可选下载，或换自有 CC0 倒计时 |

**不要选错的点**

1. **不能**因为用了 SREV（CC BY-SA）就整仓改成 CC BY-SA——CC 一般管**内容/素材**，不管应用程序源码；代码用 Apache/MIT，SREV **文件本身**继续 BY-SA + 署名即可。  
2. **不能**把 eewcn 的 AGPL「传染」过来——我们只参考 UI 分区、自写 Rust，**未拷贝其源码**时，不必被迫 AGPL。若将来**直接搬进**其 QML/C++，才必须按 AGPL 处理。  
3. **地牛 Wake Up! 倒计时 = 非自由许可**：放进公开仓库再分发，**不等于**项目「开源合规」；发行前要么授权，要么换成原创/明确可再分发素材。  
4. 走时表 / 色标：气象厅与 IASPEI 等为**数据/规范引用**，在 README/关于页署名即可，通常不决定软件用 GPL 还是 MIT。

**若你更在意「别人改了必须开源」**

| 许可 | 适用场景 |
|------|----------|
| **AGPL-3.0** | 想像 eewcn 一样强 copyleft（含网络提供服务也要开源）——社区客户端常见，但企业/闭源衍生会却步 |
| **GPL-3.0** | 分发衍生作品须开源；纯本地桌面够用，对「只跑服务不发二进制」弱于 AGPL |
| **MPL-2.0** | 折中：改过的文件要开源，链静态库更灵活 |

**本仓库现状**：GitHub [EEWView](https://github.com/Jian11323/EEWView) + 根目录 `LICENSE`（Apache-2.0）；`Cargo.toml` `license = "Apache-2.0"`。素材见 `assets/**/ATTRIBUTION.md`；关于页须列 SREV 署名。

## 1. 产品定位

| 项 | 说明 |
|----|------|
| 形态 | 桌面客户端（Windows 优先，预留 Linux / macOS） |
| 语言 | **纯 Rust**（业务、UI、音效、网络、持久化一律 Rust；禁止再引入 Qt/QML/Python 业务进程） |
| 数据 | **Jian Project API** + **Wolfx** + **P2PQuake**（见 §8） |
| UI | 深色地图主视口 + 浮动信息头 + 右栏三 Tab，对齐 eewcn 主界面分区 |
| 音效 | 默认走 SREV 事件包；倒计时专用地牛素材；原创合成包作可选/回退 |
| 走时 | 官方走时表驱动 P/S 圈与倒计时（见 §15） |
| 色标 | 官方震度色 / 烈度色（见 §16） |

**与 eewcn 的边界**

- **采用**：主窗口分区、信息头字段排布、右栏 Records / EEW / Station、左下图例条、右下倒计时/时钟区等视觉与交互骨架。
- **不采用**：Qt/C++/QML 实现、其脚本数据源耦合、其内置音效路由。
- 许可注意：eewcn 本体为 AGPL；本项目只参考界面分区，自写 Rust UI，不拷贝其源码。

## 2. 技术选型（建议）

| 层级 | 选型 | 理由 |
|------|------|------|
| 应用壳 | `eframe` + `egui` | 纯 Rust、跨平台、即时模式适合密集实时刷新；实现成本可控 |
| 地图 | **MapLibre 风格矢量/栅格瓦片**（优先对接本站 `tilemap.sismotide.top`） | 对齐 eewcn「地图中央」体验；不绑死 Mapbox 账号 |
| 地图绘制 | `egui` 内自定义 `MapView`（瓦片缓存 + 经纬投影 + 叠加层），或后续换成熟 MapLibre Native FFI | 第一期用自绘瓦片+叠加圈即可跑通；FFI 作增强 |
| 异步运行时 | `tokio` | WebSocket、定时器、文件 I/O |
| WS / HTTP | `tokio-tungstenite` + `reqwest` | 预警流 + GET 气象/配置 |
| 序列化 | `serde` / `serde_json` | 信封与配置 |
| 音效 | `rodio`（或 `kira`） | 多轨：事件提示 + 倒计时循环可叠加 |
| 配置 | `directories` + TOML/JSON | 用户目录存设置，仓库只放默认模板 |
| 日志 | `tracing` + `tracing-subscriber` | 排障 |
| 构建 | Cargo workspace | 多 crate 清晰边界 |

> 备选：若后续 UI 复杂度爆炸，可评估 `iced` / `slint`；地图若自绘不足再评估 MapLibre Native。**第一期以 egui 闭环为准。**

### 5.1 组件 ↔ eewcn 对照

### 5.2 主题

- 背景：近黑地图底 + 半透明灰信息条（对齐 `#80666666` 一类半透明头）。
- 文字：白/浅灰；强调倒计时用高对比红。
- 震度色 / 烈度色：只用 §16 官方色表，禁止自创彩虹色阶或照搬非官方客户端私货色。

### 5.3 交互约定（第一期）

- 点击列表项 → 地图居中到事件/测站，并刷新 `EventHeader`（对应 eewcn `tabViewSetMapCenter` 信号语义）。
- Legend / Home：复位视口或切换叠加层可见性。
- 倒计时仅在「本机位置有效 + 活动 EEW」时显示；否则隐藏或占位。

## 6. 音效架构（已定）

### 6.1 路由原则

| 路由键 | 包 | 说明 |
|--------|-----|------|
| **默认事件音** | **`srev/`** | 发行、更新、最终报、取消、震度档、海啸相关等 → **SREV** |
| **本地 S 倒计时** | **`countdown/`** | 地牛 `0s`…`10s`、`20/30/…/60s`、`countdown.wav` 循环 |
| `station` | `station/` | 测站强弱提示（原创，可后续改） |
| `ui` | `ui/` | 连接成功/失败、通用通知（原创） |
| `eew`（可选包） | `eew/` | 原创合成；**默认不启用**，仅作无 SREV 文件时的回退或用户自选 |

实现时以 `assets/sound/catalog.json` 为唯一路由表；启动时加载，设置页可覆盖「事件包 = srev | eew」。

**相对当前 catalog 的规划调整**

- 现稿：`default_eew` → `eew`（原创），`jma_eew` → `srev`。
- **目标**：`default_eew`（及非倒计时的主预警事件）**默认也走 `srev`**；倒计时仍固定 `countdown`。
- 实现阶段改 `routing` 字段并同步 `ATTRIBUTION.md` / 关于页署名。

### 6.2 `jian-audio` 内部模块

```text
catalog.rs      # 解析 packs / routing / events
player.rs       # 设备输出、音量、duck（倒计时压低其它轨可选）
cue.rs          # AudioCue 枚举：Issue/Update/Final/Cancel/Shindo(n)/Countdown(sec)/…
router.rs       # Cue + 当前源类型 → 文件路径
countdown.rs    # 整十秒播报 + 个位 + loop 轨的时序状态机
```

### 6.3 许可与发行

- SREV：CC BY-SA 2.0，关于页必须署名。
- 地牛倒计时：非自由许可；发行前确认授权，否则换成自有倒计时并改 catalog。
- 原创 `eew/station/ui`：CC0。

## 7. 核心领域（`jian-core`）

### 7.1 主要类型（概念）

| 类型 | 含义 |
|------|------|
| `AgencyId` | 源 ID（如 `jma-eew`、`cea`、`cenc`），与 WS `type` 对齐 |
| `EewReport` | 单次预警报文：震中、M、深度、报数、时刻、震度估计等 |
| `EqRecord` | 速报/历史列表项 |
| `StationSample` | 测站实时烈度/加速度等 |
| `LocalSite` | 用户经纬/海拔（倒计时与本地烈度估计） |
| `ActiveAlert` | 当前展示用活动预警（驱动地图圈 + Header + 倒计时） |
| `AppState` | 线程安全快照：列表、活动预警、连接健康、时钟偏移 |

### 7.2 时钟

- **EEW 时钟**：以预警源时间或本地单调钟校正后的显示钟。
- **NIED 时钟**（可选）：若接 kyoshin/NIED 类源则显示；无源则隐藏，避免伪造。

### 7.3 倒计时

1. 由 `ActiveAlert` 震中 + `LocalSite`，经 **`jian-travel`（官方走时表）** 计算 S 波剩余秒。
2. 每秒向 `jian-audio` 发 `Countdown(n)`；同时 UI 更新大号数字。
3. 禁止在无真实预警/无位置时用假数据驱动播报（对齐「禁止捏造业务字段」原则）。
4. **禁止**用恒定 7/5 km/s 直线近似作为正式倒计时（仅允许作表外远距最后兜底，并须在日志标明）。

## 8. 网络与数据（`jian-net`）

### 8.1 连接模型

```text
Config.sources[] → Connector 池（jian / wolfx / p2pquake）
       → 原始 JSON 帧
       → Adapter（按 SourceKind + 上游 type）
       → 归一化为 core 模型
       → 事件总线（tokio broadcast / channel）
       → UI 订阅 + Audio 订阅
```

各上游字段名不同，**必须在适配器内归一化**（震中、M、深度、报数、发震时刻、最大震度/烈度等）；禁止 UI 直接绑死某一家 JSON 字段名。

## 15. 地震波走时表（官方）

### 15.1 选用结论

| 优先级 | 表 | 官方来源 | 适用范围 | 用途 |
|--------|-----|----------|----------|------|
| **主表** | **JMA2001** | [气象厅：走时表・射出角表・速度構造](https://www.data.jma.go.jp/eqev/data/bulletin/catalog/appendix/trtime/trt_j.html)（`tjma2001.zip`） | 震中距约 **0–2000 km**，深度 0–700 km | EEW 本地倒计时、地图 P/S 圈（东亚场景） |
| **备选陆域** | JMA2001A | 同页 `tjma2001h.zip`（观测点标高 100 m 档） | 陆域精细 | 可选；第一期可不启用 |
| **远距/全球** | **ak135** | [IASPEI Downloads](http://www.iaspei.org/downloads)（Kennett《Seismological Tables: ak135》及 iaspei-tau） | 超出 JMA2001 距离，或需与国际定位一致 | 远震、表外兜底前一层 |
| 历史对照 | Jeffreys–Bullen (1940) | 已被 IASPEI iasp91/ak135 体系替代 | 不推荐新实现主用 | 仅文献对照 |
| 最后兜底 | 常速直线（P≈7 / S≈5 km/s） | 无 | 表插值失败时 | 须打日志；不当默认 |

> eewcn-res 的 `TravelTime.qml` 亦为 **近距 jma2001 → 远距 jb → 直线**；本项目用 **ak135 替换 jb** 作为官方远距表，避免继续依赖已过时的 JB 主表。

### 15.2 气象厅表要点（实现约束）

- 下载：`https://www.data.jma.go.jp/eqev/data/bulletin/catalog/appendix/trtime/tjma2001.zip`
- 格式说明：[走时表フォーマット](https://www.data.jma.go.jp/eqev/data/bulletin/catalog/appendix/trtime/tttfmt_j.html)（P/S 走时秒、深度 km、震中距 km）
- 网格：距离 0–50 km 步长 2 km，50–200 步长 5 km，200–2000 步长 10 km；深度类似分档
- 运行时：`tools/convert_travel_tables` 转为紧凑数组 + 双线性插值；**禁止**把未署名的第三方「走时 JSON」当官方表

### 15.3 IASPEI ak135 要点

- 软件/表：IASPEI 页提供 iaspei-tau（iasp91 / ak135）与 ak135 表册 PDF  
- 文献：Kennett, Engdahl & Buland (1995) 等  
- 关于页须注明模型名与 IASPEI / 作者出处

### 15.4 `jian-travel` API（概念）

```text
travel_time_p(depth_km, distance_km) -> seconds
travel_time_s(depth_km, distance_km) -> seconds
surface_distance_for_elapsed(wave, depth_km, elapsed_s) -> km   # 画波圈
eta_s_to_site(origin, depth, site) -> seconds                   # 倒计时
```

## 16. 震度色与烈度色（官方原版）

两套色标**并存**：日本源/震度字段用 **JMA 震度色**；中国源/烈度字段用 **中国烈度色**。`intensity_scale = auto` 时按事件所属标度切换，禁止混用色去涂另一套等级名。

### 16.1 日本：气象厅震度色（官方）

| 项 | 内容 |
|----|------|
| 文件 | [気象庁ホームページにおける気象情報の配色に関する設定指針](https://www.jma.go.jp/jma/kishou/info/colorguide/HPColorGuide_202007.pdf)（令和 2 年 7 月一部改訂） |
| 表 | **表２－２**（数値が高くなるほど危険度が増す情報の配色・震度） |
| 震度定义 | [震度について](https://www.jma.go.jp/jma/kishou/know/shindo/index.html)；計測震度换算见气象厅说明页 |

**表２－２ RGB（摘录，供实现常量；以 PDF 原文为准）**

| 震度阶级 | R,G,B |
|----------|-------|
| １ | 242, 242, 255 |
| ２ | 0, 170, 255 |
| ３ | 0, 65, 255 |
| ４ | 250, 230, 150 |
| ５弱 | 255, 230, 0 |
| ５强 | 255, 153, 0 |
| ６弱 | 255, 40, 0 |
| ６强 | 165, 0, 33 |
| ７ | 180, 0, 104 |
| ０ | 背景/未着色（指针未给专用警戒色，UI 用深灰或透明） |

津波相关配色见同指针 **表１－２**（大津波警报 / 津波警报 / 津波注意报），P2PQuake 津波情报上色时优先用该表，勿自制。

### 16.2 中国：烈度色（官方标准路径）

| 项 | 内容 |
|----|------|
| 烈度等级定义 | [GB/T 17742—2020《中国地震烈度表》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=6FD8F9071FAC980D5B2A636A9EA79DE9)（Ⅰ–Ⅻ；**标准本身不定色**） |
| **制图色/符号** | [GB/T 38226—2019《地震烈度图制图规范》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=996A838ABFB48372E05397BE0A0AD949)（附录示例与 **附录 B 地图符号参考样式**） |
| 业务语境 | 国家地震烈度速报与预警工程产出的仪器烈度/推测烈度图，制图应服从上述国标 |

**实现要求**

1. 从 **GB/T 38226—2019** 附录摘录各烈度等级填色 RGB（或官方色值），写入 `assets/palette/cn_intensity.toml`，并在 `docs/色标.md` 注明标准号、附录与摘录日期。  
2. **不要**用气象预警「红橙黄蓝」四级（那是预警等级色，不是 Ⅰ–Ⅻ 烈度色）。  
3. **不要**默认采用 CEIV / 民间客户端私货色阶冒充「国标」；若标准 PDF 暂未入库，可暂留「待摘录」占位，但合并进主界面前必须换成国标摘录值。  
4. 仪器烈度若为一位小数，按国标/台网惯例映射到整数色档后再上色。
