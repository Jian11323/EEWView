## 1. 产品定位

| 项 | 说明 |
|----|------|
| 形态 | 桌面客·端（Windows 优先，预留 Linux / macOS） |
| 语言 | 纯 Rust（业务、UI、音效、网络、持久化） |
| 数据 | Jian Project API · Wolfx · P2PQuake（见 [`数据源.md`](数据源.md)） |
| UI | ·色地图主视口 + 信息头 + 右栏三 Tab（对齐 eewcn 分区，不移植 QML） |
| 音效 | 默认 SREV；本地 S 倒计时用地牛素材（见 [`音效路由.md`](音效路由.md)） |
| 走时 | 近· JMA2001，远· ak135 |
| 色标 | 气象厅震度色 / 中国烈度制图色 |

「Jian Project」指数据站 API，不作客·端产品名。

## 4. Crate 职责

```text
jian-app ──► jian-ui / jian-map / jian-audio
               └─────► jian-core
                         ├── jian-net
                         ├── jian-travel
                         ├── jian-config
                         └── jian-util
```

| Crate | 职责 |
|-------|------|
| `jian-app` | 窗口与主循环，连接网络 / 音效 / 界面 |
| `jian-ui` | 实况栏分区：信息头、图例、倒计时、右栏列表 |
| `jian-map` | 矢量底图 / 可选瓦片、投影、测站点、震中与 P/S 波圈 |
| `jian-core` | 领域模型、色标、列表合并 |
| `jian-travel` | 走时表加载与插值 |
| `jian-net` | 三源连接与字段归一化 |
| `jian-audio` | catalog ·由与播放 |
| `jian-config` | 配置加载 |
| `jian-util` | 地理·离等公用函数 |

## 5. 主界面分区

| 组件 | 内容 |
|------|------|
| `MapViewport` | 底图、缩放平移、震中与波圈 |
| `EventHeader` | 震度色块、地名、报数、M、·度、时刻 |
| `LegendBar` | ·下：烈度/震度色标（无边框） |
| `CountdownHud` | 右下：本地时钟；有倒计时时叠在时钟上方 |
| `SidePanel` | Records / EEW / Station / Volcano；`ui.show_sidebar` 可关，右缘可拉开 |
| `SettingsPage` | 顶栏 Tab（外观 / 显示 / 音频 / 数据源 / 数据源状态 / 高级 / 关于），石色卡片布局对齐实况栏；用户目录 `settings.json` 覆盖 |

交互：点击列表 → 地图居中并更新信息头；倒计时仅在本机位置有效且存在活动预警时显示。  
侧栏可向右拖窄关闭；关闭后：地图右键菜单（设置 / 跳转所在地 / 显示图例 / 设置所在地 / 关于）；侧栏开着时右键菜单不生效。  
图例 Home：有本机经纬则居中到本机（地图青色十字），否则回到默认视口。  
设置保存：写入用户目录覆盖；数据源开关立即重连。  
底图加载：后台线程分两阶段——先要石精细世界轮廓（+钓鱼岛点状），再加载中日省级并溶解国级外轮廓；zoom ≥ 7.5 叠省级，低于此只画国级；平面/球体按投影分别加载；主线程 `poll` 合并。  
发行：Windows 预览目录由 `tools/pack_windows.ps1` 生成（`dist/StarQuake/`，不进仓库）。

## 7. 数据流

```text
配置.sources → 连接器（jian / wolfx / p2pquake）
  → 原始 JSON → 适配器 → EewReport / EqRecord
  → 事件通道 → UI 快照 + 音效触发
```

健·态对外文案：**正常 / 波动 / 异常**。详见 [`数据源.md`](数据源.md)。

## 8. 走时表

| 优先级 | 表 | 用途 |
|--------|-----|------|
| 主表 | JMA2001 | 约 0–2000 km，倒计时与波圈 |
| 远· | ak135 | 表外·离 |
| 最后回退 | 常速近似 | 插值失败时，须记日志 |

API 概念：`travel_time_p/s`、`surface_distance_for_elapsed`、`eta_s_to_site`。
