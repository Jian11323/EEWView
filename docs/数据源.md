# 数据源

配置：`config/default.toml` → `[sources.*]`  
实现：`crates/jian-net`

## 总览

| 源 | 协议 | 说明 | 访问令牌 |
|----|------|------|----------|
| **Jian** | WSS `api.sismotide.top` | 未配置令牌则不连接 `/all`；健康态为「异常」 | `JIAN_ACCESS_TOKEN`（`at_…`） |
| **Wolfx** | WSS + HTTP | `jma_eew` 推送；`cenc_eqlist.json` 填充速报列表 | 无 |
| **P2PQuake** | HTTP | `history?codes=551,552`，周期 `poll_secs` | 无（请求须带 User-Agent） |
| **Pancakes** | WSS + HTTP | `wss://api.aloys23.link/api/v1/alert/ws/all`；GQ/USGS/JMA/NMEFC/CMA/火山 | 无 |
| **测站** | WSS / HTTP | `[sources.stations]`：JMA（Jian `/kmoni` 或 NIED 原版）、S-Net、KMA | Jian 中转无需令牌 |

### 连接超限说明

IP 白名单 **不等于** 无限并发。公开路径额度已提高（预警/情报约 **6** 路、测站约 **7** 路，以服务端当前配置为准）；长期令牌另有 `max_connections`。  
若同时开着 eewcn / 网页调试 / 多个 EEWView，仍可能收到 `您已超过服务器连接限制`。关掉多余客户端后再连；本客户端遇此错误会拉长退避，避免狂重连。

上游 JSON 经适配器归一化为 `EewReport` / `EqRecord` 后进入界面快照。

## Jian Project API

| 项 | 内容 |
|----|------|
| 文档 | <https://api.sismotide.top/api/> |
| 默认地址 | `wss://api.sismotide.top/all` |
| 鉴权 | 环境变量或本机配置；勿写入公开仓库 |
| 列表 | 连接后发送 `alllist`；`*list_response` 按机构分流到预警/速报 |
| 信封 | `{ type, Data, md5 }`；聚合快照键 `source：*` |

| 上游 type | 归一类型 | 主要字段 |
|-----------|----------|----------|
| `jma-eew` / `cea` / `cea-pr` / `*-eew` | `EewReport` | id、报数、地名、经纬、深度、震级、发震时刻、震度、最终/取消 |
| `jma-tsunami` | `TsunamiInfo` | 仅 JMA：顶条 + 日本沿岸描边；优先 Jian（高于 Pancakes / P2P） |
| `cenc` 等速报 | `EqRecord` | 同上；烈度按中国烈度档映射 |

机构展示标签：`cea` → `[CN]`（预警）；`cenc` → `[CENC]`（速报，勿与 CN 混用）；`cea-pr` 按上游 `province` → `[xx地震局]`（如 `[四川地震局]`）。

### 测站（`[sources.stations]`）

| 项 | 内容 |
|----|------|
| JMA | `jma_source`：`jian`（`jma_jian_ws`，默认 `/kmoni`）／`kmoni`／`lmoni`（NIED 原版 GIF + `assets/stations/nied_point.csv`） |
| S-Net | `snet_enabled`；`jian` → `/s-net`；`original` → MSIL 切片 + `assets/stations/pixels.csv` |
| KMA | `kma_enabled` → Jian `/kma-station`（`mmi[]` → 中国烈度档展示） |
| 兼容 | 旧键 `jian.station_enabled` 与 `stations.jma_*` 启动时双向对齐 |
| 帧（中转） | 首包 `stations[]`；其后 `int[]` / `mmi[]`，缺测按源约定 |
| 归一 | 計測震度 → JMA 震度；有感写入测站列表与地图点 |

测站数据**不进入** `/all` 聚合。

## Wolfx

| 项 | 内容 |
|----|------|
| WebSocket | `wss://ws-api.wolfx.jp/jma_eew` |
| HTTP | `https://api.wolfx.jp/cenc_eqlist.json` |
| 文档 | <https://wolfx.jp/apidoc> |
| agency | `wolfx-jma-eew` / `wolfx-cenc` |
| CENC 列表字段 | `No1…` 对象；`magnitude` / `latitude` / `longitude` / `depth` / `intensity` 多为**字符串**，须按数字解析 |
| 最终 / 取消 | `isFinal` / `isCancel`，或 `Type` 含「最終」「取消」 |

## P2PQuake

| 项 | 内容 |
|----|------|
| HTTP | `history?codes=551` 与 `codes=552` 分开轮询 |
| 规范 | <https://www.p2pquake.net/develop/json_api_v2> |
| 解析 | `code=551` → 地震情报；`code=552` → 海啸情报（预报 / 注意报 / 警报） |
| WebSocket | 配置项 `ws_url`（可选） |


## PancakesAPI

| 项 | 内容 |
|----|------|
| 文档 | <https://wiki.aloys23.link/wiki/PancakesAPI> |
| 聚合 | `wss://api.aloys23.link/api/v1/alert/ws/all?clientId=…` |
| 信封 | `{ source, type, action, timestampMs, payload }` |
| GlobalQuake | `source=gq` → 预警列表；`gq_min_magnitude` 过滤 |
| USGS | `source=usgs` → 速报 |
| JMA EEW / 速报 | `jma_eew` → 预警；`jma_eqlist` → 速报 |
| 海啸 | 仅 `jma_tsunami` → 海啸条与沿岸；`nmefc` 不进海啸系统 |
| 其它 | `cma` / `jma_volcano` / `nmefc-wave` / `nmefc-surge` → 信息列表 |

## 合并与健康

| 规则 | 说明 |
|------|------|
| EEW | 同 `(agency, event_id)` 保留更高报数；列表上限 50 |
| Records | 按机构 + 地名 + 时间 + 震级去重；上限 80 |
| 地名 | 融合历史 FE 格网（`assets/place/`）；JMA / CWA / HKO / CENC 保留原文 |
| Station | 每帧有感快照替换；按震度降序，上限 120 |
| 健康文案 | **正常 / 波动 / 异常** |
