# 数据源（P3）

> 更新日期：2026-10-09  
> 实现：`crates/jian-net`；配置：`config/default.toml` `[sources.*]`

## 总览

| 源 | 协议 | 默认行为 | Token |
|----|------|----------|-------|
| **Jian** | WSS `api.sismotide.top` | 未设 `JIAN_ACCESS_TOKEN` 则**跳过连接**（健康=异常） | 需要 `at_…` |
| **Wolfx** | WSS + HTTP 冷启动 | 连 `jma_eew`；拉 `cenc_eqlist.json` 填 Records | 无 |
| **P2PQuake** | HTTP 轮询 | `history?codes=551`，周期 `poll_secs` | 无（须带 UA） |

事件经适配器归一化为 `EewReport` / `EqRecord`，经 `mpsc` 进 UI 帧循环 `apply_event`。

## Jian Project API

- 文档：<https://api.sismotide.top/api/>
- 默认 URL：`wss://api.sismotide.top/all`（单连接，避免占满公开路径并发 3）
- 鉴权：环境变量 `JIAN_ACCESS_TOKEN=at_…`（或配置 `access_token`，勿提交仓库）
- 连上后发 `alllist` 拉 cenc/cwa/jma/hko 列表
- 信封：`{ type, Data, md5 }`；`/all` 快照键 `source：*`

**归一化要点**

| 上游 type | → | 字段 |
|-----------|---|------|
| `jma-eew` / `cea` / `cea-pr` / `*-eew` | `EewReport` | id/serial/number、placeName、lat/lon、depth、magnitude、originTime、intensity |
| `cenc` 等速报 | `EqRecord` | 同上；烈度尽量映射 CN 档 |

## Wolfx

- WS：`wss://ws-api.wolfx.jp/jma_eew`
- HTTP：`https://api.wolfx.jp/cenc_eqlist.json`
- 文档：<https://wolfx.jp/apidoc>（字段以实包为准；震级键常见 `Magunitude` 拼写）

`agency` 归一为 `wolfx-jma-eew` / `wolfx-cenc`。

## P2PQuake

- HTTP：`https://api.p2pquake.net/v2/history?codes=551&limit=20`
- 规范：<https://www.p2pquake.net/develop/json_api_v2>
- `code=551` → `earthquake.hypocenter` + `maxScale`（10/20/…/70 → JMA 震度档）
- 请求须带合理 `User-Agent`（裸 urllib 易 403）

WS `wss://api.p2pquake.net/v2/ws` 预留配置项，P3 骨架以 HTTP 轮询为主。

## 合并与健康

- EEW：同 `(agency, event_id)` 保留更高 `serial`；列表上限 50
- Records：粗去重（agency+地名+时间+震级）；上限 80
- 健康文案三态：**正常 / 波动 / 异常**（`HealthStatus`）
- 无 token 的 Jian 不连网，不算失败重试风暴
