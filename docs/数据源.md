# 数据源

配置：`config/default.toml` → `[sources.*]`  
实现：`crates/jian-net`

## 总览

| 源 | 协议 | 说明 | 访问令牌 |
|----|------|------|----------|
| **Jian** | WSS `api.sismotide.top` | 未配置令牌则不连接；健康态为「异常」 | `JIAN_ACCESS_TOKEN`（`at_…`） |
| **Wolfx** | WSS + HTTP | `jma_eew` 推送；`cenc_eqlist.json` 填充速报列表 | 无 |
| **P2PQuake** | HTTP | `history?codes=551`，周期 `poll_secs` | 无（请求须带 User-Agent） |

上游 JSON 经适配器归一化为 `EewReport` / `EqRecord` 后进入界面快照。

## Jian Project API

| 项 | 内容 |
|----|------|
| 文档 | <https://api.sismotide.top/api/> |
| 默认地址 | `wss://api.sismotide.top/all` |
| 鉴权 | 环境变量或本机配置；勿写入公开仓库 |
| 列表 | 连接后发送 `alllist` |
| 信封 | `{ type, Data, md5 }`；聚合快照键 `source：*` |

| 上游 type | 归一类型 | 主要字段 |
|-----------|----------|----------|
| `jma-eew` / `cea` / `cea-pr` / `*-eew` | `EewReport` | id、报数、地名、经纬、深度、震级、发震时刻、震度 |
| `cenc` 等速报 | `EqRecord` | 同上；烈度按中国烈度档映射 |

## Wolfx

| 项 | 内容 |
|----|------|
| WebSocket | `wss://ws-api.wolfx.jp/jma_eew` |
| HTTP | `https://api.wolfx.jp/cenc_eqlist.json` |
| 文档 | <https://wolfx.jp/apidoc> |
| agency | `wolfx-jma-eew` / `wolfx-cenc` |

## P2PQuake

| 项 | 内容 |
|----|------|
| HTTP | `https://api.p2pquake.net/v2/history?codes=551&limit=20` |
| 规范 | <https://www.p2pquake.net/develop/json_api_v2> |
| 解析 | `code=551` → `earthquake.hypocenter` + `maxScale`（震度档） |
| WebSocket | 配置项 `ws_url`（可选） |

## 合并与健康

| 规则 | 说明 |
|------|------|
| EEW | 同 `(agency, event_id)` 保留更高报数；列表上限 50 |
| Records | 按机构 + 地名 + 时间 + 震级去重；上限 80 |
| 健康文案 | **正常 / 波动 / 异常** |
