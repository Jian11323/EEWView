# 自动更新

对齐滚动字幕：客户端拉取静态清单 `update/manifest.json`，**不调用** `api.github.com`（易遇 HTTP 403）。

## 清单地址（按序尝试）

1. `https://raw.githubusercontent.com/Jian11323/StarQuake/main/update/manifest.json`
2. `https://cdn.jsdelivr.net/gh/Jian11323/StarQuake@main/update/manifest.json`

## 字段

| 键 | 说明 |
|----|------|
| `latest_version` | 最新版本号（如 `2.1.0`） |
| `min_supported_version` | 最低仍支持版本（预留） |
| `channel` | 通道名，如 `stable` |
| `zip` | Windows 便携包 `{ url, sha256 }`（优先） |
| `installer` | Windows 安装包 `{ url, sha256, user_interface? }` |
| `linux` | Linux 包 `{ url, sha256 }` |
| `release_notes_url` / `html_url` | 发行说明页 |

发版时：上传 GitHub Release 资源后，改本仓库 `update/manifest.json` 的版本与 URL（可选填 sha256），推送到 `main` 即可。

当前应用版本见根 `Cargo.toml`（现为 **2.1.1**）。清单 `latest_version` 现为 **2.1.1**；已切到 manifest 的客户端会按本文件下载更新，不再依赖 GitHub API。
