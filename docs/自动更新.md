# 自动更新

客户端拉取 Gitee 上的静态清单 `update/manifest.json`，**不调用** GitHub / jsDelivr（国内易失败）。

仓库：<https://gitee.com/jian0786/starquake>

## 清单地址（按序尝试）

1. `https://gitee.com/jian0786/starquake/raw/master/update/manifest.json`
2. `https://gitee.com/jian0786/starquake/raw/main/update/manifest.json`

## 字段

| 键 | 说明 |
|----|------|
| `latest_version` | 最新版本号（如 `2.1.0`） |
| `min_supported_version` | 最低仍支持版本（预留） |
| `channel` | 通道名，如 `stable` |
| `zip` | Windows 便携包 `{ url, sha256 }`（优先） |
| `installer` | Windows 安装包 `{ url, sha256, user_interface? }` |
| `linux` | Linux 包 `{ url, sha256 }` |
| `release_notes_url` / `html_url` | 发行说明页 |

## 发版约定

Gitee Release **只保留最新一版**（附件配额有限；发新版前先删旧 Release / 附件）。

步骤：

1. 打包 Windows 安装包 / 便携包 / Linux 包
2. 删除 Gitee 上旧的 Release（及标签，如需要）
3. 创建新版 Release 并上传上述三个包
4. 改本仓库 `update/manifest.json` 的版本与 URL（填 sha256）
5. 推送到 GitHub `main`，并同步到 Gitee `master`（或运行 `python tools/publish_gitee_manifest.py`）

本机发版用私人令牌写在仓库根 `.gitee_token`（已 gitignore / 打包排除，勿提交、勿打进发行包）。

当前应用版本见根 `Cargo.toml`（现为 **2.2.0**）。清单 `latest_version` 现为 **2.2.0**。
